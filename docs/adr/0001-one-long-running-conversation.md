# One long-running conversation

PI WEB models work as projects containing workspaces and sessions. The conversations Casual targets are not project work, and a new session per topic would either pollute the Projects list or require a second navigation surface for choosing among them. V1 keeps exactly one remembered conversation in one hidden home and treats additional chats as ordinary sibling sessions, reached through **Sessions**.

## Consequences

- Reopening Casual is one click, not a picker.
- "A new conversation" means a new session in the same home, not a new space.
- Topics, folders, pins, and per-topic homes are out of scope.
- Deletion stays with PI WEB in **Sessions**; the plugin never removes history.
